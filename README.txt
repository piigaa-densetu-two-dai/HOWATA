●はじめに

ホワタは多機能USB-アタリポート変換器だという。
各種USBデバイスをMSX等の骨董PCのアタリポートに接続可能なデバイスに変換するという。

御注意: セガのゲーム機には絶対に接続しないで下さい。セガのゲームポートは骨董PCのアタリポートとは似て非なるものです。

●ホワタの対応デバイスと機能のまとめ

* 対応デバイス1

Xinput対応USBコントローラー(注)(Xbox360純正有線コントローラーとエレコムGP20S以外は動作未確認)

機能1: FMタウンズ6ボタン兼アタリ2ボタンコントローラーに変換(FMタウンズは動作未確認)
機能2: JOYMEGA(MSX)6ボタン兼アタリ2ボタンコントローラーに変換
機能3: チェルノブ6ボタンコントローラーに変換(動作未確認)

(注)DirectInputには対応しません

* 対応デバイス2

USBマウス

機能1: アタリマウスに変換
機能2: MSX版アルカノイド/アルカノイド2コントローラーに変換

* 対応デバイス3

Windowsの標準USB-MIDIドライバーを使用するUSB-MIDIデバイス、
ヤマハ製の専用ドライバーを使用するUSB-MIDIデバイスの一部(注)(MDP-5以外は動作未確認)

機能1: MSX用MIDIプレイヤーのMIDRY/SZMMPのへろへろ5号出力をUSBに変換

●使い方

対応USBデバイスをホワタのUSBタイプAコネクターに接続、ホワタを骨董PCのアタリポートに接続し、骨董PCの電源を投入します。
ホワタ脱着の際はホワタ本体をしっかりと持って脱着して下さい。タイプCコネクターには何もつながないで下さい。
ホワタは接続されたUSBデバイス種別に応じた動作モードになります。
USBデバイスのホットスワップは出来ないのでUSBデバイスを交換する場合は通電し直してください。

●各モードの詳細

* Xinput対応USBコントローラー変換モード

ホワタがXinput対応USBコントローラーを認識するとコントローラー変換モードとなり底面のLEDが緑色に点灯します。
このモードには以下の3モードがあり、モードはガイドボタンを押す毎に1->2->3->1->2->3...の順序で変化します。
(モードによりLEDの明るさが変わります)

モード1(明度高): FMタウンズ6ボタン兼アタリ2ボタンコントローラーに変換(デフォルトのモード)
モード2(明度中): JOYMEGA(MSX)6ボタン兼アタリ2ボタンコントローラーに変換
モード3(明度低): チェルノブ6ボタンコントローラーに変換

モード1ボタンマップ

USBコントローラー -> FMタウンズコントローラー

十字パッド上下左右 -> 上下左右
A,B,RT -> A,B,C
X,Y,RB -> X,Y,Z
BACK(注) -> SELECT
START(注) -> RUN

(アタリ2ボタンコントローラーとして使用する場合はAがトリガー1、Bがトリガー2となります)

モード2,3ボタンマップ

USBコントローラー -> メガドライブコントローラー

十字パッド上下左右 -> 上下左右
A,B,RT -> A,B,C
X,Y,RB -> X,Y,Z
BACK(注) -> MODE
START(注) -> START

(JOYMEGAモードをアタリ2ボタンコントローラーとして使用する場合はBがトリガー1、RT(C)がトリガー2となります)

(注)BACK/STARTボタンは製品によってはVIEW/MENUボタンと命名されているようです

* USBマウス変換モード

ホワタがUSBマウスを認識すると1秒後にアタリマウス変換モードとなり、底面のLEDが赤色に点灯します。
アタリマウス変換モードになるまでの1秒間の間にマウスの左右ボタンを同時押しするとアルカノイドコントローラー変換モードとなり、底面のLEDが桃色に点灯します。

アタリマウス変換モード、アルカノイドコントローラー変換モード共に中ボタンを押すと移動速度が5段階に変化します。
デフォルトは最高速でボタンを押す毎に5(速)->4->3->2->1(遅)->5(速)->4->3->2->1(遅)...の順序で変化します。
(速度に応じてLEDの明るさが変化します。速->明度高 遅->明度低)

* USB-MIDIデバイス変換モード

ホワタが対応USB-MIDIデバイスを認識するとUSB-MIDI変換モードとなり、底面のLEDが青色に点灯します。
(MIDI信号処理中はLEDが点滅します)

MIDRY/SZMMPからホワタを使用する場合のインターフェース指定オプション

MIDRY(アタリポート1) /I31
MIDRY(アタリポート2) /I32
SZMMP(アタリポート1) /K又は/U6
SZMMP(アタリポート2) /J又は/U4
